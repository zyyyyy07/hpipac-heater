# 触摸屏界面规则

手术中看屏幕的人很紧张、戴着手套、可能站在两米外。屏幕只回答三个问题:**现在在哪一步、一切正常吗、下一步按什么**。其他数字都放到“详情”里。

## 1. 主屏只有四块

```
┌──────────────────────────────────────────────────────┐
│ 喷雾  第 3 步 / 共 5 步            12:30   [详情] [中止] │  顶栏 72 px
├──────────────────────────────┬───────────────────────┤
│ 腹腔温度                     │ 下一步                │
│   41.4 ℃      [已到温]       │ 启动注射泵推药。       │
│   目标 42.0                  │ 推完后按下面的按钮。   │
│ ─────────────────────────    │                       │
│ ✓ 药液 42.0 ℃                │                       │
│ ✓ 加热气体 42.0 ℃            │ ┌───────────────────┐ │
│ ✓ 腹腔压力 12 mmHg           │ │  喷雾结束          │ │  主按钮 ≥ 96 px 高
│ ✓ 雾化气 正常                │ └───────────────────┘ │
├──────────────────────────────┴───────────────────────┤
│ 一切正常                                              │  状态栏 48 px
└──────────────────────────────────────────────────────┘
```

1. **顶栏**:阶段名(最大的字)、“第几步 / 共几步”、计时(暴露阶段显示剩余时间)、“详情”、“中止”。中止永远在右上角同一个位置,永远看得见。
2. **腹腔温度**:全屏最大的数字。旁边一个状态标签,只有三种:**升温中**(灰)、**已到温**(绿)、**过高**(红)。
3. **四项检查**:药液、加热气体、腹腔压力、雾化气。每项一行:勾或叉、名称、一个数字。全部打勾就是一切正常。没打勾的那一项变成黄色或红色,并写明差多少。
4. **下一步**:一两句话说现在该做什么,下面是唯一的主按钮,写着这一步要做的事。这一阶段不需要人做事时,主按钮不出现,改写“无需操作,等待……”。

不在主屏上的:加热功率百分比、加湿罐出口温度、保护传感器读数、流量设定值。它们在“详情”里。

## 2. 报警时整个右半边变成报警卡

报警时不再显示“下一步”,右半边换成报警卡,红色(高级)或黄色(中级):

- 第一行:**发生了什么**,例如“喷头堵塞”。
- 第二行:**设备已经做了什么**,例如“循环泵已停”。
- 编号的处理步骤,最多三步,第一步永远是最要紧的。喷雾中停泵时,第一步是“立即停止注射泵”。
- 两个按钮:**确认报警**(大)和**消音**。

多个报警同时出现时,卡片显示最严重的一个,下面写“还有 N 个报警”。

## 3. 防误触

- 中止、提前结束暴露:按下后弹出全屏确认,“确认”在左、“取消”在右,10 秒不按自动取消。
- 实体中止键按下直接停,不需要确认。
- 设置只在“详情”里改,每项用大号 − + 按钮,改完按“应用”才生效。

## 4. 看得清

- 只用深色底。颜色只表示状态:绿 = 正常,黄 = 注意,红 = 报警,灰 = 未到温或未启用。不用颜色做装饰。
- 最小字号 20 px,数字用等宽字体。所有可以按的东西至少 64 px 高,戴手套能按准。
- 任何内容都不能被裁切或滚动;800×480 的屏上放不下就删,不缩小字号。

## 5. 各阶段主屏写什么

| 阶段 | 第几步 | 下一步 | 主按钮 |
| --- | --- | --- | --- |
| 待机 | — | 装好喷头和回路、建立气腹后开始预热。 | 开始预热 |
| 预热 | 1 / 5 | 等待各项到温,到温后自动进入就绪。腹腔温度可以不等,手动确认。 | 不等腹腔,直接就绪(四项里药液和气体都打勾才可按) |
| 就绪 | 2 / 5 | 按“开始喷雾”,等雾化气压稳定后启动注射泵。 | 开始喷雾 |
| 喷雾 | 3 / 5 | 启动注射泵推药。推完后按下面的按钮。 | 喷雾结束 |
| 暴露 | 4 / 5 | 无需操作。药雾停留,剩余时间见右上角。 | 不显示主按钮(提前结束在“详情”里) |
| 排气 | 5 / 5 | 经密闭排气系统排空气腹。排完后按下面的按钮。 | 排气完成 |
| 结束 | — | 本次记录已保存。 | 回到待机 |
