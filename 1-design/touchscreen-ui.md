# 触摸屏界面规则

照病人监护仪和 HIPEC 灌注机的做法:**大数字、短标签、主屏上没有句子**。看屏幕的人戴着手套、站在一米外、处在紧张状态,一眼要能看到三件事:在哪一步、数字正不正常、该按哪个键。

## 依据

| 来源 | 规定或做法 | 本机怎么用 |
| --- | --- | --- |
| IEC 60601-1-8(医用报警) | 报警信号在操作位置 1 m 处可辨认;可选 4 m 处能分辨报警级别。高级报警红色、闪烁;中级黄色。旧版 ISO 9703-1 给的高级报警闪烁频率是 1.4–2.8 Hz | 报警占屏幕顶部整条,高级红色以 2 Hz 闪,中级黄色常亮;盒盖上的红黄灯同步 |
| IEC 62366-1、FDA 人因工程指南 | 界面设计要减少使用错误,按真实用户做形成性和验证性测试 | 本规则只是设计输入,真机到手后要请外科医生和护士做模拟使用测试 |
| 病人监护仪的通行做法 | 每个参数一个数字块:短标签、大数字、小单位;报警时整块变色 | 主屏五个数字块,每块只有标签、数字、目标值 |
| HIPEC 灌注机(Belmont、Performer HT 等) | 温度用 T1 入水、T2 出水、T3 腹腔这样的短标签显示;高对比度;有用户反映显示太小,外科医生看不清腹腔温度 | 腹腔温度做成全屏最大的数字 |

以上标准条文我只读到了摘要和二手资料,具体数值以标准原文为准。

## 主屏

```
┌──────────────────────────────────────────────────────┐
│ 预热 › 就绪 › [喷雾] › 暴露 › 排气           12:30   │  顶栏 64:报警时整条变红/黄
├────────────────────────┬─────────────┬───────────────┤
│ 腹腔 ℃                 │ 药液 ℃      │ 气体 ℃        │
│                        │  42.0       │  42.0         │
│   41.4                 ├─────────────┼───────────────┤
│                        │ 腹压 mmHg   │ 雾化 kPa      │
│ 目标 42.0              │  12         │  45           │
├────────────┬───────────┴─────────────┴───────────────┤
│  [中止]    │            [ 喷雾结束 ]          [详情]  │  底栏 104
└────────────┴─────────────────────────────────────────┘
```

1. **顶栏**:五步流程条,当前一步高亮;右边计时。暴露阶段计时换成剩余时间。
2. **五个数字块**:腹腔(最大)、药液、气体、腹压、雾化。每块只有三样东西:2 个字的标签带单位、数字、小字目标值。数字正常是白色;没到温是灰色;超出范围是黄色;危险是红色,同时整块底色变红。没用到的块(比如非喷雾阶段的雾化)显示“—”。
3. **底栏**:左边中止,位置永远不变;中间是这一步唯一的主按钮,只写动作,2–4 个字;右边详情。这一步不需要人操作时(预热中、暴露中),主按钮位置显示一个大的状态,比如“升温中”或“剩余 24:18”,不能按。

主屏上**不出现句子**。说明文字、传感器明细、加热功率、曲线、设置,全部在“详情”里。

## 报警

- 顶栏整条变色,写**报警名(不超过 6 个字)· 第一步动作(不超过 6 个字)**,例如“喷头堵塞 · 停注射泵”。高级红色闪烁,中级黄色常亮。
- 出问题的那个数字块同时变色。
- 底栏主按钮换成“确认报警”,旁边是“消音”。
- 处理步骤的详细说明在“详情”第一页,不放主屏。
- 多个报警时顶栏显示最严重的一个,后面加“+2”。

## 字号和尺寸(800×480,7 英寸屏,约 1 m 看)

| 内容 | 字号 |
| --- | --- |
| 腹腔温度 | 120 px |
| 其他数字 | 64 px |
| 标签、按钮、顶栏 | 28 px |
| 目标值、单位 | 24 px(主屏最小) |

主屏和确认画面的按钮至少 96 px 高;“详情”里的设置按钮至少 64 px 高、字至少 20 px(五项设置放不下 96 px 的按钮)。颜色只表示状态,不做装饰。只用深色底。

中止键在待机、排气、结束时变灰但不挪位置。只是提示、不需要确认的报警(比如雾化气压偏低)出现时,底栏保留这一步的操作按钮,旁边是消音。

## 防误触

- 中止、提前结束暴露:全屏确认,确认在左、取消在右,10 秒不按自动取消。
- 实体中止键按下直接停,不确认。
- 设置只在“详情”里改。

## 各阶段底栏

| 阶段 | 主按钮或状态 |
| --- | --- |
| 待机 | 开始预热 |
| 预热 | 状态“升温中”(四项到温后自动进入就绪;“不等腹腔直接就绪”在详情里) |
| 就绪 | 开始喷雾 |
| 喷雾 | 喷雾结束 |
| 暴露 | 状态“剩余 mm:ss”(提前结束在详情里) |
| 排气 | 排气完成 |
| 结束 | 回到待机 |
