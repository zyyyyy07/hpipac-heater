# 第 6 步 · 架服务器、设置触摸屏

喷雾和暴露期间人员要离开手术间,所以这套软件的主角是**手术控制台**:在手术间外的电脑上看腹腔温度、阶段和倒计时,并下发命令。这一步不需要硬件也能做,可以最先做,先用模拟器看到整套软件的效果。

> **只能在隔离的测试网络里用。** 样机服务器没有登录、没有加密,任何能打开页面的人都能给设备发命令。不要接入医院业务网。不要填写任何真实病人信息,“手术编号”一栏填编号,不要填病人姓名。

## 运行服务器

任意一台装了 Python 3.9 以上的电脑,和设备在同一个网络里。不需要安装任何依赖,页面不引用任何外网资源,断网可用。

```
cd 6-software
python server.py
```

默认端口 8080,用环境变量 `PORT` 改。数据(`data.json`、操作日志 `audit.jsonl`、手术记录 `cases/*.csv`)默认写在本目录,用环境变量 `HP_DATA_DIR` 改到别处。

## 没有硬件时:运行模拟器

另开一个窗口:

```
python simulator.py http://127.0.0.1:8080 1 20
```

三个参数依次是服务器地址、设备台数、加速倍数。上面这行会出现一台 `HP-001`,时间加速 20 倍(预热到就绪大约 1 分半钟)。模拟器刚启动时设备在待机,要在控制台上点“开始预热”它才会动。

要看报警是什么样,加 `--fault`,写法是 `名称@开始秒数[+持续秒数]`,秒数按设备时间算:

```
python simulator.py http://127.0.0.1:8080 1 20 --fault ip_high@600
python simulator.py http://127.0.0.1:8080 1 20 --fault lid@120+60,press_high@400
```

可用的名称:`ip_high`、`overtemp_drug`、`overtemp_gas`、`sensor`、`sensor_open`、`press_high`、`press_low`、`water_low`、`lid`。各自的含义见 `python simulator.py --help`。

模拟器里的升温快慢是随手取的数,只为了让画面看起来像样,**不能用来估计真机的升温时间**。

## 三个页面

| 地址 | 用途 |
| --- | --- |
| `http://电脑IP:8080/` 或 `/console` | **手术控制台。** 阶段条和倒计时、腹腔温度、药液和气体温度、压力、流量、最近 30 分钟曲线、报警条。每个阶段只给出当前该做的那一个操作,加一个始终在的“中止”(要再确认一次)。先在右上角填操作人才能操作。设置、开始和结束手术记录、下载 CSV 也在这一页 |
| `/panel?dev=HP-001` | **主机面板模拟。** 不用硬件看主机盖板的样子:触摸屏、红黄绿指示灯、中止键、消音键、蜂鸣器。上面的中止和消音键会真的给设备发命令 |
| `/local?dev=HP-001` | **本机页面。** 主机 7 英寸触摸屏(800 × 480)上显示的就是这一页:阶段、四路加热和循环泵的温度/设定/输出、腹腔温度、压力,以及和控制台相同的阶段操作 |

另有 `/cases`,列出历次手术记录并提供 CSV 下载。

一次手术的操作顺序:填操作人 → 填手术编号,点“开始记录” → 开始预热 → 自动就绪(或手动确认就绪)→ 开始喷雾 → 喷雾结束,开始计时 → 计时到自动转排气(或提前结束)→ 结束手术 → 确认,回到待机 → 结束记录,下载 CSV。

接口、阶段、报警的含义以 [../1-design/interface-spec.md](../1-design/interface-spec.md) 为准。

## 设置触摸屏

主机里的树莓派负责驱动触摸屏。给树莓派装好带桌面的 Raspberry Pi OS、连上同一个网络后,把 [kiosk/setup-kiosk.sh](kiosk/setup-kiosk.sh) 拷过去运行一次:

```
sh setup-kiosk.sh http://电脑IP:8080 HP-001
```

重启后会自动全屏打开 `/local?dev=HP-001`。这个脚本没有在树莓派上运行过。

## 自测

```
python test_flow.py
```

脚本自己在 8091 端口起服务器和模拟器,数据放临时目录,用接口走完一次手术,再查拒绝命令、中止、故障注入、CSV、曲线接口、离线判定、转义、重启后数据是否还在。约 40 秒,最后一行应为 `ALL PASS`。

## 已知的限制

- 没有登录,操作人是自己填的名字,只用于记日志,不能当作身份认证。
- 命令在服务器里排队,等设备下一次上报(2 秒一次)时带回去;排队超过 30 秒没被取走就作废。设备离线时服务器拒绝一切命令,这时要中止只能按主机上的中止键。
- 曲线数据只放在内存里(每台设备最近 2 小时),服务器重启后曲线从头开始;手术记录 CSV 和操作日志在磁盘上,不受影响。
