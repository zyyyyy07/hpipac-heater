# 第 3 步 · 加工铝板、打印外壳

这一步把 8 个定制零件做出来:两片铝板找 CNC 加工厂,六个塑料件 3D 打印。

| 文件 | 做法 | 说明 |
| --- | --- | --- |
| [models/cnc/](models/cnc/)`01_plate_lower_AL6061.step` | CNC,6061 铝 | 下板。4 个 Ø2.5 孔攻 M3。侧面 2 个 Ø2.2 深 20 测温孔 |
| [models/cnc/](models/cnc/)`02_plate_upper_AL6061.step` | CNC,6061 铝 | 上板,与下板镜像。4 个 Ø3.4 通孔。侧面 1 个测温孔 |
| [models/print/](models/print/)`03/04_heater_shell_*.stl` | 3D 打印 PETG | 加温模块上下壳。铝板面比壳口高约 0.3 mm,保证两片铝板直接贴合。下壳一侧有两个绑带耳,用来把模块固定在床栏或床面上 |
| [models/print/](models/print/)`05_drip_sensor_clip.stl` | 3D 打印,黑色 | 卡在滴斗中部。默认孔径 17 mm,先量你们的滴斗外径,不合适就在三维查看器里改“滴斗外径” |
| [models/print/](models/print/)`06_loadcell_mount.stl` | 3D 打印,100% 填充 | 称重传感器固定座。固定端 2×M5,另一端悬空挂钩 |
| [models/print/](models/print/)`07/08_control_box_*.stl` | 3D 打印 | 主控盒和盖。盖上开了 7 英寸触摸屏可视窗(155×87)、3 个 LED、2 个按键、蜂鸣器孔;触摸屏玻璃从盒内用 3M VHB 双面胶贴在盖板背面;侧面 5 个接口孔 |

- 给 CNC 厂的要求:槽用 R2 球头刀,槽面 Ra ≤1.6,槽口去毛刺,合模面平面度 0.05。台架阶段不做阳极氧化。
- 下单前先量输液管外径。槽按外径 4.1 mm 设计,偏差大时在三维查看器里改“单片槽深”。
- 发给加工厂:图纸是 [drawings/IW-drawings.pdf](drawings/IW-drawings.pdf)(每个零件一张 A3,含孔表、公差和技术要求),二维线稿在 [drawings/dxf/](drawings/dxf/)。铝板发第 1、2 页加 `models/cnc/` 里的两个 STEP;打印件发 `models/print/` 里的 STL 或 STEP。图纸由脚本生成,下单前请加工厂确认能否按图加工。
- 看模型和改尺寸:`pip install cadquery reportlab ezdxf` 后进入 [tools/](tools/) 运行 `python studio.py`,浏览器打开 `http://127.0.0.1:8095`。可以旋转、剖切、看整机装配、拖滑块改尺寸,点“保存并导出”后模型和图纸按新尺寸重新生成。
- 主控盒只是一个能装下模块的起点,模块的固定位置需要你们按实物在盒底打孔或贴双面胶。

## 加温模块怎么固定(重要)

加温模块连线缆大约 0.5 kg(两片铝板约 390 g,外壳、加热片、螺丝约 90 g)。**它不能吊在输液管上。** 输液器的接头按标准只保证承受 15 N(约 1.5 kg)的静拉力 15 秒,0.5 kg 的静重虽然没超,但病人一动就会有冲击,拉力还会直接传到穿刺点,管子被拉细也会改变流速。

正确的放法:

- 模块平放在病人手边的床面上,或贴着床栏,用魔术贴绑带穿过下壳的两个耳固定。
- 输液管在模块进口和出口两端各留 10 cm 以上的松弛,不绷紧。
- 线缆用扎带固定在一个耳上,拉线缆时力落在外壳上,不落在输液管和插头上。
- 线缆 1.5 m,沿输液架或床栏走,不要悬空横跨过道。

这些是按重量和标准算出来的,没有做过受力仿真或实物拉力试验,[第 7 步](../7-testing/README.md)的 T16 会实测。
