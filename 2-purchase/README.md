## 由医院提供、不在本清单里的

高压注射器和针筒、高压管、雾化喷头、气腹机、穿刺器、密闭排气系统。本系统不改动它们。

**下单前先量三个尺寸**,结构件要按它们加工:注射筒外径、高压管外径、加湿罐底面直径。

台架测试还需要:经计量的温度计、细热电偶和记录仪、模型腹腔(密闭塑料箱加硅胶膜)、水柱压力计、生理盐水。
