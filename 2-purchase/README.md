普通呼吸湿化罐和输气管是按很低的压力设计的。本方案里它们在泵的出口侧,要承受几十 kPa。**买不到耐压的,就要把加湿罐放进一个耐压外罩里,或者改成泵在加湿罐之后。** 这一点我没有解决,见[第 7 步](../7-testing/README.md)的风险点。

## 由医院提供、不在本清单里的

注射泵和针筒、气腹机、穿刺器、密闭排气系统。本系统不改动它们。

**下单前先量两个尺寸**:注射筒外径、加湿罐底面直径。

台架测试还需要:经计量的温度计、细热电偶和记录仪、模型腹腔(密闭塑料箱加硅胶膜)、水柱压力计、电子天平(0.01 g)、食用色素或荧光素、生理盐水。测雾滴粒径需要激光粒度仪,通常要找有设备的实验室。
